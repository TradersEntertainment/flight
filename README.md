# flight ✈🚗⛵

Tarayıcıda çalışan, **gerçek dünya haritası** üzerinde geçen açık dünya aracı oyunu:
gerçek uydu görüntüleri + gerçek topografya üzerinde **uçak** (ana odak), **araba** ve
**gemi** ile serbest dolaşım — gece modunda NFS Carbon estetiği. İlham: [hop.earth](https://hop.earth).
